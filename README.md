# mbsites-block-recover-password

Este es un plugin para WordPress desarrollado para bloquear la funcionalidad de recuperación de contraseña.

## Descripción

Este plugin impide que los usuarios utilicen la opción de "¿Olvidaste tu contraseña?" en el formulario de inicio de sesión de WordPress, aumentando así la seguridad del sitio al evitar el restablecimiento de contraseñas por parte de usuarios no autorizados.

## Instalación

1. Descarga el archivo `mbsites-block-recover-password.php`.
2. Sube el archivo a la carpeta `wp-content/plugins/` de tu instalación de WordPress.
3. Activa el plugin desde el panel de administración de WordPress en la sección de "Plugins".

## Uso

Una vez activado, el plugin bloqueará el acceso a la funcionalidad de recuperación de contraseña para todos los usuarios.
